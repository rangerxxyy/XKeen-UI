# Аудит XKeen UI

Проверки на 14 октября 2026 года. Источники кода и ограничения см. также в [`docs/REFERENCE_AUDIT.md`](docs/REFERENCE_AUDIT.md). Подтверждённые риски отделены от ещё не доказанных предположений.

## Подтверждённые риски

| ID | Приоритет | Доказательство | Последствие | Действие |
|---|---|---|---|---|
| RISK-01 | Высокий | В upstream `zxc-rv/XKeen-UI` отключение DNS ставит `77.88.8.8` вместо восстановления исходного списка; состояние DoH/DoT и фильтра не восстанавливается. См. `backend/src/dns.rs` исследованной ревизии. | Откат меняет настройки сети пользователя, а не возвращает исходные; пропадают secure DNS и может измениться фильтрация. | Не переносить алгоритм отключения. Реализовать полный снимок Keenetic RCI, журнал транзакции, проверку, rollback с mock-тестами. |
| RISK-02 | Высокий | DNS handoff, изменение фильтра Keenetic, системные конфиги и Xray service controls не имеют полного RCI/config transaction adapter и rollback. | Эти операции нельзя считать реализованными или проверенными. | Продолжать только через snapshots, allowlist путей, mock-сбои и атомарное восстановление; не включать опасный DNS-переключатель до покрытия rollback. |
| RISK-03 | Средний | Источники форков и установщик ядер реализованы: GitHub asset allowlist, SHA-256, ELF ARM64, backup, проверка активного конфига и восстановление при неудаче. | Сборка подтверждает код, но не совместимость каждого форка или поведение на пользовательском роутере. | CI и isolated lifecycle — обязательны для каждого релиза; установка/обновление активного ядра на пользовательском устройстве отдельно не выполнялись. |
| RISK-04 | Средний | Установщик скачивает GitHub Release `latest`; v0.1.0 создан раньше updater/logs/UI версии 0.2.0. | Однострочную установку на текущий код нельзя считать готовой до выпуска нового архива и checksum. | Опубликовать ARM64 archive и SHA256SUMS для v0.2.0, проверить их загрузку из GitHub и только затем выдать curl команду. |
| RISK-05 | Средний | `zxc-rv/assets` содержит шаблоны, но в закреплённом дереве не найден файл LICENSE. | Условия распространения шаблонов отдельной лицензией не подтверждены. | Приложение загружает шаблоны по требованию напрямую из исходного хранилища и показывает источник; не vendoring/не включать шаблоны в релиз, пока лицензия не выяснена. |
| RISK-06 | Средний | Навигация, журнал, core updater и log endpoint добавлены в последние коммиты; CI проверяет frontend/backend/lifecycle/AArch64 отдельно. | До завершения Actions точный commit не считается подтверждённым. | Сверять release только с зелёным CI SHA и собирать archive из его ARM64 artifact. |
| RISK-07 | Средний | Целевые доли TypeScript/Rust/Shell — ориентир состава, а GitHub Linguist включает тесты и сопутствующие исходники. | Добавление защищённой системной логики увеличивает Rust долю. | Проверить свежую статистику после последнего push; не переносить привилегированные файловые операции в TypeScript ради процента. |

## Не подтверждено

- Живое включение/отключение управления DNS и content filter на целевом роутере не выполнялось.
- Установка XKeen UI на роутер, нагрузочный профиль на целевом устройстве, чтение журнала новым endpoint и rollback ядра не проверялись.
- Текущая GitHub ветка и CI не доказывают корректность каждого Mihomo/Xray fork; принимаются только совместимые GitHub Release assets ожидаемого формата.
- Локальный интерфейс открыт в браузере; без локального Rust backend API возвращает HTTP 500, поэтому данные selectors/logs не подтверждены визуально с настоящим backend.
