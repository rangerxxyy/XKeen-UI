# Аудит XKeen UI

Проверки на 14 октября 2026 года. Источники кода и ограничения см. также в [`docs/REFERENCE_AUDIT.md`](docs/REFERENCE_AUDIT.md). Подтверждённые риски отделены от ещё не доказанных предположений.

## Подтверждённые риски

| ID | Приоритет | Доказательство | Последствие | Действие |
|---|---|---|---|---|
| RISK-01 | Высокий | В upstream `zxc-rv/XKeen-UI` отключение DNS ставит `77.88.8.8` вместо восстановления исходного списка; состояние DoH/DoT и фильтра не восстанавливается. См. `backend/src/dns.rs` исследованной ревизии. | Откат меняет настройки сети пользователя, а не возвращает исходные; пропадают secure DNS и может измениться фильтрация. | Не переносить алгоритм отключения. Реализовать полный снимок Keenetic RCI, журнал транзакции, проверку, rollback с mock-тестами. |
| RISK-02 | Высокий | В нашем коде нет RCI mutation adapter для DNS, Xray управления или конфигов устройства. | Нельзя считать destructive operations проверенными или доступными. | Оставить реальное изменение состояния заблокированным до реализации адаптера и независимой mock-матрицы сбоев. |
| RISK-03 | Средний | Источники форков сейчас сохраняются; загрузчик релизов и проверка подписей/хешей ядер отсутствуют. | Настройка источника пока не устанавливает и не обновляет ядро. | Следующий этап — GitHub releases API, архитектурный allowlist asset, checksum, staging, backup/rollback. |
| RISK-04 | Средний | Установщик скачивает только GitHub Release `latest`; GitHub Release этого репозитория пока не создан. | Пользовательскую install-команду пока нельзя считать рабочей. | Создать и проверить архивы UI по архитектурам и `SHA256SUMS`, затем проверить команду против опубликованного release. |
| RISK-05 | Средний | `zxc-rv/assets` содержит шаблоны, но в закреплённом дереве не найден файл LICENSE. | Условия распространения шаблонов отдельной лицензией не подтверждены. | Приложение загружает шаблоны по требованию напрямую из исходного хранилища и показывает источник; не vendoring/не включать шаблоны в релиз, пока лицензия не выяснена. |
| RISK-06 | Средний | `main` содержит пользовательский код providers/template chooser; GitHub CI после публикации требуется дождаться. | Локальная TS-сборка не подтверждает rustfmt, Rust tests/build и Entware target. | Финальный статус выдавать по конкретному commit CI, не только по локальной сборке. |
| RISK-07 | Средний | GitHub language API на момент последнего запроса показывал TypeScript 69,766 B, Rust 31,541 B, Shell 10,863 B; это общий байтовый подсчёт GitHub без специального исключения тестов и вспомогательных исходников. | Доли проекта не попадают в ориентиры пользователя; крупный installer Shell особенно завышает долю. | Пересчитать целевой код отдельно и сокращать/перепроектировать Shell только вместе с проверкой install lifecycle, не удалением нужных гарантий. |

## Не подтверждено

- Живое включение/отключение управления DNS и content filter на целевом роутере не выполнялось.
- Установка XKeen UI на роутер, нагрузочный профиль на целевом устройстве и rollback ядра не проверялись.
- Текущая GitHub ветка и CI не доказывают корректность каждого Mihomo/Xray fork; принимаются только совместимые GitHub Release assets ожидаемого формата.
- Визуальная проверка новых элементов настроек и «Утилиты» в реальном браузере не выполнена.
