# Карта возможностей XKeen UI

Состояние на 18 октября 2026 года, ветка выпуска v0.4.1. «Реализовано» означает наличие функции и соответствующих проверок в проекте, но не подтверждает работу на пользовательском роутере.

| ID | Сценарий | Статус | Ограничение |
|---|---|---|---|
| UI-01 | Панель, навигация, адаптивные селекторы/соединения, журнал | Реализовано | Журнал обновляется автоматически; пользовательский роутер в этой проверке не использовался |
| UI-02 | Настройки панели и доступ | Частично | Полного аккаунтного и сессионного auth flow нет; не выставлять в интернет без VPN/авторизованного шлюза |
| CORE-01 | Версии, скачивание, проверка и установка Mihomo/Xray | Реализовано | Сборка и CI проверяются; эксплуатация зависит от платформы и установленной конфигурации |
| MIHOMO-01 | Версия, группы, правила, providers и соединения Clash API | Реализовано | Изменяющие действия требуют подтверждения; runtime на роутере отдельно не проверен |
| CONFIG-01 | YAML Mihomo и JSON/JSONC Xray редактор | Реализовано частично | Семантическая проверка зависит от активного ядра; применению предшествуют резервирование и проверка |
| CONFIG-02 | Каталог и импорт шаблонов по активному ядру | Реализовано | Шаблон создаёт/изменяет черновик; каталог закреплён на upstream assets SHA `8747e7b02af1631fff048bf2d832d3e5370bdb34` |
| CONFIG-03 | Импорт ссылок прокси и AmneziaWG | Реализовано частично | Форматы и поля ограничены поддержанными парсерами |
| CONFIG-04 | Ручная проверка/форматирование/скачивание черновика из меню | Удалено | Эти действия не отображаются как доступные функции |
| DNS-01 | DNS-запрос через Mihomo | Реализовано | Read-only диагностика; не изменяет системные DNS роутера |
| DNS-02 | Редактирование Enhanced Mode и resolver полей Mihomo | Реализовано | Проверка конфигурации и откат; Xray DNS отдельно не поддержан |
| DNS-03 | Передача IPv4 DNS KeeneticOS → Mihomo и возврат | Реализовано с ограничениями | IPv6, DoH/DoT и content filter могут обходить передачу; проверка на устройстве не выполнялась |
| DNS-04 | Английские имена DNS-полей с русскими подсказками | Реализовано | Подсказки доступны наведением и фокусом клавиатуры |
| SYS-01 | Статус и управление сервисом XKeen | Реализовано | Системные изменения выполняются на роутере и требуют штатных защитных проверок |
| SYS-02 | Фильтрация и просмотр журнала | Реализовано | Файлы логов ограничены allowlist; очистка UI не удаляет файлы на устройстве |
| DEFER-01 | Geo scan, полный route tester, HTTP subscription preview | Не реализовано | Требуют отдельной реализации и проверки ресурсов/безопасности |
| DEFER-02 | Multi-router plugin config и полноценные аккаунты/сессии | Не реализовано | Не входят в v0.4.1 |
