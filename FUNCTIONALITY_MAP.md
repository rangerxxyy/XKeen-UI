# Карта возможностей XKeen UI

Состояние на 14 октября 2026 года. «Реализовано» означает, что функция существует в текущей ветке и соответствующие проверки перечислены в `TESTING.md`; это не подтверждает безопасную работу на пользовательском роутере.

| ID | Сценарий | Модуль | Статус | Критерий / ограничение |
|---|---|---|---|---|
| UI-01 | Адаптивная панель и состояния загрузки/ошибки | `src/main.ts`, `src/style.css` | Реализовано | Самостоятельный интерфейс, без точного копирования референса; нужна визуальная проверка в браузере |
| UI-02 | Настройки панели и ключа доступа | `src/main.ts`, `src/api.ts` | Частично | Вкладки общие/безопасность; теста полного auth flow нет |
| CORE-01 | Настройка URL репозиториев Xray и Mihomo/форков | Settings API, `src/main.ts`, `src/core-releases.ts` | Реализовано частично | URL проверяются/сохраняются; GitHub API показывает совместимые ARM64 assets; UI только просматривает релизы |
| CORE-02 | Выбор релиза, скачивание, checksum, установка/обновление/откат ядра | Rust updater | Не начато | Просмотр не устанавливает ядро; нужен release asset allowlist, checksum и безопасный rollback |
| MIHOMO-01 | Чтение версии, групп, правил и providers | `backend/src/mihomo.rs`, `src/api.ts` | Реализовано | Только read-only API Mihomo |
| MIHOMO-02 | Переключение узла селектора | `backend/src/mihomo.rs`, `src/mihomo-view.ts` | Реализовано | Проверка состава группы и обновление фактического состояния после команды |
| MIHOMO-03 | Список и закрытие соединений | Mihomo API/UI | Реализовано | Одно/все соединения требуют подтверждения; реальный роутер не тестировался |
| DNS-01 | DNS lookup в Mihomo | `backend/src/mihomo.rs`, `src/dns-view.ts` | Реализовано | Read-only, строгая проверка запроса, нет live DNS handoff |
| DNS-02 | Mihomo DNS settings и DNS Xray | UI/API | Не начато | Нужны два независимых адаптера и проверка конфигурации ядра |
| DNS-03 | Передача DNS KeeneticOS → Mihomo, отключение фильтра и полный rollback | RCI transaction adapter | Не начато | Сначала snapshot всего DNS/DoH/DoT/DoU и content-filter engine/profile assignments; тесты только на mock; нет подключения к роутеру |
| CFG-01 | Mihomo YAML и Xray JSON/JSONC редакторы | `src/yaml-editor.ts` | Реализовано частично | YAML/JSON/JSONC синтаксическая проверка и форматирование; нет схемной семантики и безопасного применения к устройству |
| CFG-02 | Шаблоны Mihomo и Xray в меню «Утилиты» | `src/templates.ts` | Реализовано частично | Каталог/9 шаблонов загружаются из закреплённой ревизии; выбор заменяет только вкладочный черновик; лицензия отдельно описана в аудите |
| CFG-03 | Импорт подключений, AmneziaWG, резервные копии, geo scan, route test | UI/modules | Не начато | Добавлять в меню только после реализации проверяемой операции, не показывать фиктивные кнопки |
| CFG-04 | Сохранение, резервная копия, применение и откат системных конфигов | Rust file/config service | Не начато | Ограничение корня, snapshot, atomic apply, проверка результата и восстановление |
| SYS-01 | Статус приложения, памяти и load average | `backend/src/main.rs` | Частично | Режим роутера читает системные показатели; действия сервисов не реализованы |
| SYS-02 | Логи и диагностика | Backend/UI | Не начато | Нужны ограниченные чтение/фильтрация и redaction секретов |
| INST-01 | Entware installer на порту 1001 | `install.sh`, `backend/src/installer.rs` | Реализовано частично | Shell отвечает за загрузку/checksum; Rust — install/update/remove/service и rollback. Текущие изменения ещё не проверены CI; router-install не запускался |
| QUAL-01 | Rust 37–38%, TS 55–60%, Shell 2–3% | LOC исходников | Не достигнуто | После переноса lifecycle в Rust пересчитать LOC; не использовать байтовую статистику GitHub как LOC |
