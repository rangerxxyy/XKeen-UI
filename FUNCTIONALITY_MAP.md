# Карта возможностей XKeen UI

Состояние на 18 октября 2026 года, v0.5.6. Наличие тестов подтверждает только покрытое ими поведение и не доказывает работу на пользовательском роутере. Последующие UX-правки находятся в [PR #55](https://github.com/rangerxxyy/XKeen-UI/pull/55); целевые проверки RSS, latency, live DNS и применения подписки остаются отдельными.

| ID | Сценарий | Статус | Ограничение |
|---|---|---|---|
| UI-01 | Панель, навигация, адаптивные селекторы/соединения и журнал | Реализовано | Маршрут соединения отображается слева направо компактными подписями и стрелками с SVG-иконками сервисов; очистка журнала скрывает строки только в браузере |
| UI-02 | Фильтр, выбор файла, очистка и полноэкранный журнал | Реализовано | Копирование и скачивание удалены; системные файлы read-only |
| CORE-01 | Просмотр, установка и обновление Mihomo/Xray | Реализовано с ограничениями | Совместимость release assets зависит от выбранного GitHub-источника и платформы |
| MIHOMO-01 | Mihomo версия, селекторы, соединения, providers, правила и DNS query | Реализовано | Требует доступного Clash API и работающего Mihomo |
| CONFIG-01 | Редактирование и применение Mihomo YAML и Xray JSON/JSONC | Реализовано с ограничениями | Откат и применение зависят от поддерживаемого ядра; Xray конфигурация может состоять из нескольких файлов |
| CONFIG-02 | Каталог шаблонов по активному ядру | Реализовано | Два Mihomo YAML и Xray JSON-фрагменты закреплены по upstream assets; импорт изменяет черновик до явного сохранения/применения |
| CONFIG-03 | Импорт ссылок прокси и AmneziaWG | Реализовано частично | Поддерживаются только форматы из парсеров; требуется тестировать секреты и редкие URI-поля |
| CONFIG-04 | Ручные действия проверки, форматирования и скачивания черновика в меню | Удалено | Не отображаются как доступные функции |
| DNS-01 | DNS-запрос через Mihomo | Реализовано | Только диагностика, системный DNS не меняется |
| DNS-02 | Enhanced Mode и resolver-поля Mihomo с подсказками | Реализовано | Семантическая валидность конкретной схемы зависит от Mihomo |
| DNS-03 | Передача IPv4 DNS KeeneticOS → Mihomo и возврат | Реализовано с ограничениями | DNS status показан; IPv6, DoH/DoT и контент-фильтр не полностью контролируются; live router не проверен |
| DNS-04 | Имена параметров DNS и пояснения | Реализовано | Tooltip доступен наведением и клавиатурным фокусом |
| SYS-01 | Статус и управление службой XKeen | Реализовано | Реальные системные операции требуют роутерного режима и не подтверждены на пользовательском устройстве |
| SYS-02 | API backend, чтение статуса, логов, файлов и управление ядром | Реализовано | Полной пользовательской серверной аутентификации/сессий нет; same-origin защита изменяющих запросов не является авторизацией |
| DEFER-01 | Geo scan, полный route tester и HTTP subscription preview | Не реализовано | Нужны отдельный дизайн, лимиты и валидация ресурсов |
| DEFER-02 | Multi-router/plugin configuration и полноценные аккаунты/сессии | Не реализовано | Отдельный будущий этап; не публиковать панель в интернет без VPN или авторизованного шлюза |
| DEFER-03 | Xray DNS и полное сохранение/возврат DoH/DoT и content filter | Не реализовано | Требует транзакционного recovery и проверки Keenetic API |

Источники: пользовательские запросы и скриншоты; `docs/v0.4-audit.md`; `docs/ARCHITECTURE.md`; тесты в `src/` и `backend/`.
