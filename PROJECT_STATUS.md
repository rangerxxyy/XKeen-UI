# Состояние проекта

## Кандидат v0.4.4 — 18 октября 2026

Последние правки улучшают читаемость маршрутов иконок в таблице соединений, переводят маршрут в явную последовательность узлов со стрелками и упрощают version chip. Кнопка «Открыть релиз» удалена из окна обновления XKeen UI; остаётся выбор версии и установка.

Локально пройдены 219 frontend-тестов, typecheck, production build и `git diff --check`. Rust-команды недоступны в текущей Windows-среде; backend, installer и Linux AArch64 проверки ожидают GitHub CI. Публикация ещё не выполнена.

## Предыдущий релиз v0.4.3 — 18 октября 2026

Обновлены DNS-подсказки и размеры Nameserver-полей; статусы DNS приведены к обозначениям zxc-rv и сведены с переключателем управления. В журнале удалены копирование и скачивание, кнопки очистки/полноэкранного режима выровнены, добавлен полноэкранный режим с Escape и улучшена читаемость текста.

Релиз: https://github.com/rangerxxyy/XKeen-UI/releases/tag/v0.4.3. Исходный commit `56c27ea`; все четыре CI jobs прошли в run `39124537081`. Публичный AArch64 архив повторно скачан и проверен по манифесту SHA-256: `d5096477683f8751fa3b751b1d8eb7e80b7fde97358f24870271f3c70d37a681`. Локально: 216 frontend-тестов, typecheck и production build пройдены.

## Перед v4.0

Текущие запросы по журналу, шаблонам конфигурации и DNS воплощены, но v4.0 ещё не готов. Главный пробел — отдельной серверной аутентификации с сессиями нет: контроль same-origin для изменяющих запросов не является авторизацией. Полная обратимость DNS, некоторые Xray multi-file сценарии и live-проверка на Keenetic также остаются неподтверждёнными. Приоритеты, критерии проверки и отложенный объём находятся в `PLAN.md`.

На реальном пользовательском роутере v0.4.3 не тестировался. Не выставлять панель в открытый интернет без VPN или отдельного авторизованного reverse proxy.
