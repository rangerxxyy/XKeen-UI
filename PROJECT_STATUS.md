# Состояние проекта

## Релиз v0.4.5 — 18 октября 2026

Кнопка Mihomo открывает управление обоими ядрами. Для установленного ядра доступно «Обновить», для отсутствующего — «Установить»; выбор релиза открывается отдельным окном. Маршруты соединений упрощены до читаемых подписей со стрелками. При доступном обновлении XKeen UI версионная кнопка получает бирюзовую обводку, а в правом нижнем углу появляется уведомление с номером версии и ссылкой на GitHub. Уведомление сверено с публичным [zxc-rv/XKeen-UI](https://github.com/zxc-rv/XKeen-UI/blob/main/frontend/src/components/ui/toast.tsx).

Локально пройдены 223 frontend-теста, TypeScript typecheck, production build и `git diff --check`. Все четыре CI jobs прошли на коммите `63ae3e6` в run `39127397086`. Публичный AArch64 архив повторно скачан; SHA-256 совпал с CI-манифестом: `fa2bd1bc20beb7c0916e0a99e4aa949d648fd2c741daccf69fcc30a56ca8b407`.

Релиз: https://github.com/rangerxxyy/XKeen-UI/releases/tag/v0.4.5. На реальном Keenetic не тестировался.

## Кандидат выпуска v0.5.0 — 18 октября 2026

Текущие запросы по журналу, шаблонам конфигурации и DNS воплощены; версия в манифестах установлена на v0.5.0. Нерешённые пункты UX, проверка Rust CI и live-проверки перечислены в `PLAN.md`. Релиз пока не опубликован. Серверная аутентификация с сессиями требует отдельного проектирования; контроль same-origin для изменяющих запросов не является авторизацией.

### Работа по скриншотам (не выпущено)

Исправлено в рабочей ветке: Xray release picker принимает prerelease с совместимым ARM64 архивом и помечает статус; окно релизов показывает заметки и indeterminate прогресс загрузки/установки; DNS status использует English labels и выводит Router DNS Servers, а предупреждение показывается только при подтверждении включения; конфигурационные файлы открываются read-only и переходят в редактирование по клику; резервные копии стоят последними в утилитах; индикатор сервиса пульсирует с учётом `prefers-reduced-motion`; ping и кнопка закрытия соединения стали заметнее. Добавлен раздел «Прокси-подписки» с runtime-списком узлов. Импорт подписки позволяет выбрать proxy-groups и связывает provider через `use`; тесты проверяют YAML, загрузку provider-узлов и формирование селекторов. Проверки frontend: 235 тестов, TypeScript и production build проходят. Это не релиз; Rust CI, визуальная проверка полного сценария и проверка на роутере ещё не пройдены.

На реальном пользовательском роутере v0.4.3 не тестировался. Не выставлять панель в открытый интернет без VPN или отдельного авторизованного reverse proxy.
