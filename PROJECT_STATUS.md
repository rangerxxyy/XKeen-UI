# Состояние проекта

## Версия 0.1.0 — первый вертикальный срез

- Добавлены TypeScript UI, Rust read-only API и POSIX Shell installer scaffold.
- API по умолчанию использует порт 1001.
- Simulation mode изолирован от системных процессов и настроек роутера.
- Router mode только читает `/proc`, `/proc/meminfo` и `/proc/loadavg`; управляющие операции отсутствуют.
- Router mode требует сгенерированный установщиком 256-битный bearer token для API. UI хранит его в `sessionStorage` только в текущей вкладке.
- Конфигурация получила CodeMirror YAML-редактор: черновик в `sessionStorage`, локальная YAML 1.2-проверка, форматирование и скачивание. Это не проверка схемы Mihomo; чтения/применения на роутере нет.
- DNS, selectors, connections, логи, резервирование/применение/откат и получение версий ядер ещё не реализованы.
- Обработчик авторизации есть; полноценное управление учётными записями и защита CSRF для изменяющих endpoints ещё не реализованы (изменяющих endpoints пока нет).
- Целевая среда подтверждена на роутере: KeeneticOS/Entware, AArch64, glibc 2.27.
- Тестовый AArch64-бинарник собран в CI с Entware dynamic loader (`/opt/lib/ld-linux-aarch64.so.1`) и успешно проверен на устройстве на loopback-порту 18473: `/health`, отказ API без bearer-токена, read-only status с токеном и раздача frontend.
- После проверки тестовый процесс остановлен, временный каталог `/tmp/xkeen-ui-test-…` удалён. Существующие службы и файлы Entware не менялись.
- Репозиторий опубликован на GitHub. README удалён по просьбе пользователя, release и публичная инструкция установки не публиковались. CI-артефакт сборки предназначен только для проверки.
- Installer прошёл ShellCheck и синтаксическую проверку, но его установка и управление службой на устройстве не проверялись.

## Среда

- Доступны Git, GitHub CLI, Node.js и pnpm workspace runtime.
- Локальная Windows-среда не содержит Rust/MSVC linker; Rust format, tests и build выполняются в GitHub Actions.
- Последний CI запуск успешен: frontend typecheck/build, Rust fmt/tests/build, POSIX shell/ShellCheck и AArch64 Entware cross-build.
- Аудит структуры и исходников двух референсов собран в `docs/REFERENCE_AUDIT.md`; на устройстве проверена только read-only связность backend и выдача UI.

## Следующие шаги

1. Зафиксировать фактические API и расположение конфигураций Mihomo/Xray без изменений на устройстве.
2. Реализовать отдельными вертикальными срезами selectors/connections, DNS, логи и безопасную работу с конфигурацией; подтвердить контракты тестовыми ответами до включения операций изменения.
3. Для каждого изменения на роутере сначала подготовить план отката и ограничить операции тестовым окружением.
4. Перед публикацией install release отдельно согласовать готовность пользовательской установки; до этого не создавать release-артефакты.
