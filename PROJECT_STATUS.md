# Состояние проекта

## Релиз v0.5.4 — опубликован 18 октября 2026

В релиз входят исправления RAM-метрики через Keenetic RCI с резервным источником, кэш статуса DNS с ручным обновлением, мгновенный отклик при выборе узла и fallback GitHub API через сохранённые прокси. Обновлены строки соединений и действия редактора; DNS-статусы отображаются без дополнительной подложки. В конфигурацию добавлены импорт AmneziaWG с маскировкой ключей в предпросмотре и полезные ссылки.

Frontend-тесты (255), typecheck, production build, Rust fmt/tests/release build, install/update/remove smoke и AArch64 cross-build прошли в локальных проверках и GitHub Actions. Примечания: [docs/release-notes-v0.5.4.md](docs/release-notes-v0.5.4.md). Релиз: https://github.com/rangerxxyy/XKeen-UI/releases/tag/v0.5.4. Реальный Keenetic в этой среде недоступен для проверки.

## Релиз v0.5.3 — 18 октября 2026

Подготовлен выпуск на базе опубликованной v0.5.2. Рабочая область селекторов, соединений, DNS и конфигурации получила общую округлую рамку; пункты навигации оформлены отдельными кнопками с собственными SVG-значками и явным активным состоянием. Файлы конфигурации остаются справа в отдельной рамке на той же строке. В соединениях сервис, направление и узлы маршрута отделены и выровнены; фон панели и строк затемнён. В карточках селекторов маршрут показан стрелкой без подписи «Куда:».

Локально пройдены 243 frontend-теста, TypeScript typecheck и production build. Все четыре GitHub CI jobs (frontend, backend, installer и AArch64) прошли в run `39138512562`. Публичный AArch64 архив и `SHA256SUMS` сверены; SHA-256 архива: `8a40a3bb16fd14b6b3899ad390ce609a357dd9b8504c62e7b779315e72c444d0`.

Релиз: https://github.com/rangerxxyy/XKeen-UI/releases/tag/v0.5.3. На реальном роутере не проверялось.

## Релиз v0.4.5 — 18 октября 2026

Кнопка Mihomo открывает управление обоими ядрами. Для установленного ядра доступно «Обновить», для отсутствующего — «Установить»; выбор релиза открывается отдельным окном. Маршруты соединений упрощены до читаемых подписей со стрелками. При доступном обновлении XKeen UI версионная кнопка получает бирюзовую обводку, а в правом нижнем углу появляется уведомление с номером версии и ссылкой на GitHub. Уведомление сверено с публичным [zxc-rv/XKeen-UI](https://github.com/zxc-rv/XKeen-UI/blob/main/frontend/src/components/ui/toast.tsx).

Локально пройдены 223 frontend-теста, TypeScript typecheck, production build и `git diff --check`. Все четыре CI jobs прошли на коммите `63ae3e6` в run `39127397086`. Публичный AArch64 архив повторно скачан; SHA-256 совпал с CI-манифестом: `fa2bd1bc20beb7c0916e0a99e4aa949d648fd2c741daccf69fcc30a56ca8b407`.

Релиз: https://github.com/rangerxxyy/XKeen-UI/releases/tag/v0.4.5. На реальном Keenetic не тестировался.

## Остающиеся ограничения

Серверная аутентификация с сессиями требует отдельного проектирования; same-origin-проверки изменяющих запросов не являются авторизацией. На реальном Keenetic изменения v0.5.1 ещё не проверялись. Не выставлять панель в открытый интернет без VPN или отдельного авторизованного reverse proxy.
