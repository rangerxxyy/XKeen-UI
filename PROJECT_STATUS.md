# Состояние проекта

## Выпуск v0.4.1 — 18 октября 2026

В релиз включены изменения после v0.4.0: обновлённый журнал без паузы, шаблоны для активного ядра Mihomo/Xray, удаление неготовых действий редактора и улучшенный DNS-раздел. DNS-поля названы на английском и имеют русские пояснения при наведении и фокусе. Передача DNS касается IPv4; IPv6, DoH/DoT и фильтр контента не контролируются полностью.

Релиз опубликован: https://github.com/rangerxxyy/XKeen-UI/releases/tag/v0.4.1. Итоговый коммит `253199b`; все четыре CI jobs прошли в run `39121693568`. Архив Linux AArch64 скачан из этой сборки, содержимое проверено, SHA-256 совпал с манифестом: `bb8b9c71475416920486e1a6bfc1eee37e2827de0ae7030ee56e26b704640b44`. На реальном пользовательском роутере v0.4.1 не проверялся.

Отложены: Geo scan, полный route tester, предпросмотр HTTP-подписок, multi-router через плагины, полноценные аккаунты/сессии, полный контроль DoH/DoT и content filter. Не выставлять панель в открытый интернет без VPN или авторизованного шлюза.
