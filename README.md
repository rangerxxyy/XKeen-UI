# XKeen UI

## Быстрый запуск

В терминале роутера Keenetic с Entware выполните одну команду:

```sh
curl https://raw.githubusercontent.com/rangerxxyy/XKeen-UI/main/install.sh | sh
```

В меню выберите установку, обновление или удаление. Установщик скачивает последний ARM64-пакет напрямую с GitHub, проверяет SHA-256 и сохраняет предыдущую версию при обновлении. Каждый запрос к GitHub ограничен 30 секундами. Новая установка выбирает первый свободный порт, начиная с `1001`; обновление сохраняет текущий порт.
