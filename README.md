# XKeen UI

## Быстрый запуск

В терминале роутера Keenetic с Entware выполните одну команду:

```sh
curl -fsSL https://raw.githubusercontent.com/rangerxxyy/XKeen-UI/main/install.sh | sh
```

В меню выберите установку, обновление или удаление. Установщик сначала скачивает последний ARM64-пакет напрямую с GitHub, проверяет SHA-256 и сохраняет предыдущую версию при обновлении. Если запрос не удался за 30 секунд, он пробует настроенные GitHub-зеркала. Панель доступна на порту `1001`.
