# XKeen UI — вариант 1

Первая самостоятельная версия панели управления XKeen для KeeneticOS/Entware. Интерфейс использует предоставленные пользователем скриншоты и запись как UX-референсы, но имеет собственную композицию. Пока это безопасный read-only каркас: он не подменяет статусы примерными значениями и не запускает управляющие операции.

## Что входит

- TypeScript frontend с адаптивной тёмной панелью, навигацией и обзором статуса.
- CodeMirror 6 YAML-редактор черновика с локальной подсветкой, синтаксической проверкой, форматированием и скачиванием файла.
- Rust backend на Axum: `GET /health`, `GET /api/v1/status`, порт по умолчанию `1001`.
- Simulation mode для локальной разработки без чтения или изменения состояния роутера.
- Linux router mode, который только проверяет `/proc` на наличие процессов. Он пока не управляет ими и не получает версию ядра.
- POSIX Shell установщик с выбором install/update/remove, проверкой контрольной суммы архива и backup текущей версии.

Селекторы, соединения, DNS, ядра и логи отмечают дальнейшую работу. Они не отображают тестовые данные и пока не выполняют операции. YAML-черновик хранится в текущей вкладке; его проверка не сверяет конфигурацию со схемой версии Mihomo и не применяет её.

## Разработка

Нужны Node.js + pnpm и Rust stable.

```powershell
pnpm install
pnpm dev
```

В отдельном PowerShell:

```powershell
cd backend
$env:XKEEN_MODE = 'simulation'
$env:XKEEN_PORT = '1001'
cargo run
```

Production frontend собирается в `release/web`, его раздаёт тот же Rust backend на `http://localhost:1001`.

## Установка

Installer скачивает release-артефакт под архитектуру устройства и требует SHA-256 manifest. Пока подходящий release не опубликован, он завершится с ошибкой до изменения системы. Установка на реальный роутер не проверялась.

После подтверждения публичности репозитория, target-архитектуры и опубликованного release команда установки с портом 1001 будет:

```sh
curl -fsSL https://raw.githubusercontent.com/rangerxxyy/XKeen-UI/main/install.sh | sh -s -- install --port 1001
```
