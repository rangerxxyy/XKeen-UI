# Безопасность — XKeen UI 0.1.0

- HTTP API пока содержит только read-only endpoints; единственный защищённый endpoint — `/api/v1/status`.
- Simulation mode не запускает системные команды и не читает конфигурации роутера.
- Router mode только просматривает имена процессов в Linux `/proc`; он не запускает, останавливает и не сигналит процессы.
- Не добавлять управляющие endpoints до проектирования и проверки авторизации.
- Router mode отказывается запускаться без `XKEEN_TOKEN`. Installer создаёт 256-битный случайный ключ, сохраняет его в Entware config с правами `0600` и один раз выводит в терминал. UI сохраняет ключ только в `sessionStorage` текущей вкладки.
- `/health` и статические файлы доступны без ключа и не возвращают системные данные.
- Installer требует интерактивного подтверждения и SHA-256 manifest для загружаемого архива.
- До появления login/session/CSRF-механизма не добавлять изменяющие HTTP endpoints. Текущая bearer-проверка предназначена только для read-only API и не является заменой полноценной модели учётных записей.
- Не журналировать пароли, токены, subscription URLs или содержимое конфигураций.
- Release должен указывать target и содержать checksum; установка неподходящей архитектуры недопустима.
