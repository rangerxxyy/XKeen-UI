# XKeen UI v0.3.1

## Исправления

- Обновление и переустановка сохраняют установленный порт панели. Если он занят, операция завершается с ошибкой вместо незаметного перехода на другой порт.
- Индикатор запуска, остановки и перезапуска XKeen показывает отдельную анимацию процесса и понятный статус сервиса.
- Error Log получает журнал фонового запуска XKeen, ошибки Xray и ошибки YAML/конфигурации панели.
- Из Error Log убраны успешные события перезапуска, штатный SIGTERM, отменённые ping-запросы и внутренние сообщения обновлятора.
- Успешные операции управления XKeen больше не записываются как ошибки.
