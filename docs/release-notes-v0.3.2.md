# XKeen UI v0.3.2

## Журнал

- Убраны старые записи об успешных перезапусках UI и блокировках, которые загромождали Error Log.
- Удалены управляющие ANSI-коды из сообщений запуска и остановки.
- Сообщения Xray теперь отображаются с локальным временем, микросекундами и уровнем INFO/ERROR, как в журнале zxc-rv.
- Источники журналов больше не добавляются в конец текста каждой записи.
