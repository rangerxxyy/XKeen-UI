# XKeen UI v0.3.6

## Интерфейс соединений

- Добавлена работающая сортировка таблицы по маршруту, хосту, типу соединения, источнику, трафику и времени.
- Поиск находит адреса, маршруты и названия устройств, отображаемые вместо IP.
- Адреса IPv4 и IPv6 корректно показывают порт назначения.
- Сохранены иконки сервисов и выравнивание маршрутов.

## Статус, журнал и настройки

- Уменьшен повторяющийся шум в журнале и улучшена читаемость строк.
- Обновлены индикаторы RAM/CPU, кнопки управления XKeen, DNS, конфигурация и фиолетовая тема.

Проверки: 190 frontend-тестов, TypeScript typecheck, production build, GitHub CI и ARM64-сборка.
