# XKeen UI v0.4.1

Patch-релиз включает изменения, влитые после v0.4.0: обновлённый журнал без паузы, импорт шаблонов по выбранному ядру и улучшения редактора конфигурации. DNS-раздел объединяет статус, настройки Mihomo и диагностику. Для DNS-полей добавлены английские названия и русские пояснения при наведении или фокусе.

`redir-host` возвращает реальные IP-адреса, обычно обеспечивает более широкую совместимость и рекомендуется большинству пользователей. `fake-ip` возвращает виртуальные адреса и работает быстрее, но может конфликтовать с исключениями и политиками XKeen. Передача управления DNS затрагивает IPv4; статические IPv6 DNS и DoH/DoT могут обходить её.

Из меню редактора убраны ручные действия проверки, форматирования и скачивания черновика. Не входят в выпуск: Geo scan, полный тест маршрутов, HTTP subscription preview, multi-router через плагины и полноценные аккаунты/сессии. DoH/DoT и фильтр контента не управляются полностью.

Проверки: 215 frontend-тестов, TypeScript typecheck, Vite production build и `git diff --check` прошли локально. GitHub Actions для точного коммита и артефакт Linux AArch64 проверяются отдельно; архив будет опубликован с `SHA256SUMS` только после успешного CI и повторной сверки скачанных файлов. Проверка на пользовательском роутере не проводилась.
