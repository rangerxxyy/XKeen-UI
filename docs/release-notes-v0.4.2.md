# XKeen UI v0.4.2

Релиз исправляет карточку DNS Status: подсказки открываются ниже значка и больше не обрезаются границами списка. Обозначения соответствуют экрану статуса: `DNS Override`, `DNS Mihomo`, `Слушатель 53 порта`; активное состояние показано как `Активно`.

Постоянная кнопка управления DNS заменена переключателем, который отображает текущее состояние. Изменение по-прежнему требует отдельного подтверждения; если статус роутера неизвестен, переключатель недоступен. Передача относится к IPv4 DNS: статические IPv6 DNS и DoH/DoT могут обходить её.

Очистка журнала запоминается отдельно для каждого файла в браузере. Старые записи остаются в системных файлах роутера, но не появляются в интерфейсе после перезагрузки страницы; новые записи показываются как обычно.
