# XKeen UI v0.5.1

## Изменения

- Удалена отдельная страница «Прокси». Данные подписок по-прежнему используются селекторами, а импорт подписок остаётся доступен в утилитах конфигурации.
- Переработано отображение соединений по примеру zxc-rv: маршрут больше не слипается, переходы отделены, для начального и конечного узлов используются реальные иконки Mihomo, столбцы выровнены.
- Выбор файла конфигурации вынесен в отдельную скруглённую панель в фиолетовой палитре интерфейса.
- Удалены подсказка «Просмотр · нажмите на поле, чтобы редактировать» и суффикс «проверка Mihomo при сохранении».
- Названия состояния DNS и переключателя управления DNS показаны на русском.
