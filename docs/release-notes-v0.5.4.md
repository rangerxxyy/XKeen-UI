# XKeen UI v0.5.4

## Исправления

- Статус памяти получает общий объём из Keenetic RCI и показывает округлённый объём устройства; при недоступности RCI остаётся резервное чтение `/proc/meminfo`.
- Статус DNS кэшируется между переходами по разделам. Кнопка «Обновить статус» запускает запрос по требованию, а изменения DNS обновляют кэш принудительно.
- Переключение узла сразу обновляет выбранное значение; при ошибке интерфейс возвращает прежний выбор и показывает сообщение.
- Список релизов Xray и Mihomo сначала запрашивается напрямую, а при сетевом отказе или ограничении GitHub использует сохранённые GitHub-прокси.

## Интерфейс

- В меню «Конфигурация» перемещена перед DNS, как указано в порядке разделов для релиза.
- В разделе DNS убрана строка DNS-серверов роутера; статусные значения размещены без отдельной подложки.
- В таблице соединений затемнён фон, увеличен размер подписей, сохранены иконки узлов из данных селекторов и расширена зона кнопки закрытия.
- В редакторе конфигурации «Применить» расположено левее «Сохранить»; журнал скрыт, пока открыт редактор.
- Индикатор работающего XKeen мягко пульсирует раз в две секунды и отключает анимацию при `prefers-reduced-motion`.
- В утилиты редактора добавлены импорт `.conf` AmneziaWG и вложенное меню полезных ссылок на документацию Xray, Mihomo и XKeen.
- Предпросмотр импортированной конфигурации маскирует криптографические ключи; импорт добавляется в локальный черновик для проверки и явного применения.

## Проверки и ограничения

- Frontend: 255 тестов, TypeScript, production build и локальный HTTP-smoke для приложения.
- Rust backend и AArch64 пакет требуют GitHub CI; локальное Windows-окружение не содержит Cargo.
- Изменения не проверялись на реальном Keenetic.
