# XKeen UI v0.5.8

Эта версия добавляет управление подписками Mihomo и просмотр rule-set, а также полирует пинг в селекторах, FAQ-подсказки и диалоги обновления.

## Изменения

- В разделе «Подписки» отображаются proxy-providers Mihomo: число узлов, тип источника, использование и лимит трафика, срок действия и последнее обновление. Можно отфильтровать список, посмотреть узлы провайдера и обновить один или все источники.
- Ссылки `https://` в сценарии добавления прокси обрабатываются как Mihomo `proxy-provider`; фронтенд-тесты проверяют генерацию и выбор целевых групп.
- Кнопка «Рулсеты» открывает список и содержимое rule-set из конфигурации Mihomo. Просмотр ограничен 10 МБ; для MRS используется конвертер Mihomo.
- Уточнены цветовые уровни и выравнивание ping, FAQ-подсказки и иконки/оформление окон обновления.

## Проверки и ограничения

- GitHub Actions прошёл typecheck, все frontend-тесты, production build, installer checks, backend tests/release build/lifecycle smoke и AArch64 musl cross-build.
- Локально прошли 279 тестов, typecheck и production build. Vite отдал страницу с кодом HTTP 200 и показал разделы, кнопки «Подписки»/«Рулсеты» и журнал. Без локального backend на порту 1001 API-запросы ожидаемо вернули HTTP 500; живые API-сценарии этим не подтверждены.
- На целевом роутере нужно проверить RSS/PSS панели, задержку переключения, обновление реальной подписки и DNS handoff/rollback.
