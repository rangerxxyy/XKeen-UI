# XKeen UI v0.6.0

## Изменения

- Кнопки «Рулсеты» и «Подписки» находятся справа в строке навигации; «Рулсеты» расположены первыми.
- Основные разделы упорядочены как «Селекторы», «Соединения», «Конфигурация», DNS.
- Провайдеры правил фильтруются от proxy-groups, а просмотр rule-set обрабатывает BOM и распространённые inline-записи провайдеров.
- Значок обновления XKeen UI заменён на белую иконку коробок.
- Цифры ping остаются высококонтрастными, выровненными в углу карточки и используют tabular numerals.

## Проверки и ограничения

- Локально проверены frontend-тесты, TypeScript, production build и чистота diff.
- GitHub Actions проверяет frontend, installer, Rust backend/lifecycle и статическую ARM64 musl сборку.
- На роутере не проверены RSS/PSS, задержка переключения, DNS handoff/rollback и применение реальной подписки. Это требует целевого устройства.
