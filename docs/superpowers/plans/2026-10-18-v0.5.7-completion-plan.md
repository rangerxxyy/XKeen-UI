# XKeen UI v0.5.7 Completion Plan

> **For agentic workers:** Execute task by task, test first for behavior changes, and record evidence in the matching SDD ledger.

**Goal:** complete and verify the user's original XKeen UI checklist, then prepare v0.5.7 only after the code, CI, local smoke, and target-router gates are satisfied.

**Architecture:** Keep the existing TypeScript/Vite frontend and Rust/Axum router backend. Audit current `main` plus PR #55 against the original acceptance list, compare matching upstream `zxc-rv/XKeen-UI` source, then make focused changes with tests at the UI/API/config boundary.

**Tech Stack:** TypeScript, Vitest, Vite, Rust, Axum, Tokio, GitHub Actions, Keenetic RCI/Mihomo APIs.

**Spec:** `docs/superpowers/specs/2026-10-18-v0.5.4-product-design.md`, plus the user's original request sections 3.1–3.10 and follow-ups in the task conversation.

## Global Constraints

- The installed release remains v0.5.6 until every applicable gate is verified; candidate release version is v0.5.7.
- Preserve user router configuration and existing safe staging, checksum, backup, rollback, and DNS protections.
- Do not claim real-router RSS, switching latency, or live subscription results without fresh measurements on the target router.
- Keep low-resource behavior, keyboard/touch access, readable dark/light themes, and secret redaction.
- Compare exact upstream code at a recorded commit before treating it as a behavioral or visual reference.

## Review Focus

- Slow/rejected/overlapping selector writes and concurrent connection cleanup; prove the final selection is current and later clicks are not blocked.
- DNS management failure at each mutation step; prove full rollback or keep the operation gated and clearly report it as unavailable.
- Release assets with unexpected names, architecture, malformed HTML, or unsafe changelog links; only compatible ARM64 binaries may be installable.
- Imported subscriptions with base64, URI escaping, duplicate nodes, unsupported schemes, and secrets; preserve values and redact secrets from logs/previews.
- RAM metric source/units and long-lived router RSS; separate a correct displayed total from actual process memory consumption.
