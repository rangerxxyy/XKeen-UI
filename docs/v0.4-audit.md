# Аудит XKeen UI v0.4.3

Аудит выполнен 18 октября 2026 года по `main` после публикации v0.4.3. Проверены сообщения/скриншоты пользователя, реализация и тесты в репозитории, а также публичный `zxc-rv/XKeen-UI`. Отдельного технического задания-файла в рабочем каталоге нет, поэтому пользовательские требования восстановлены только из сообщений и скриншотов; функции, встреченные только в upstream, не считаются требованием пользователя.

## Сверка с upstream

GitHub API на дату аудита сообщает upstream `main` SHA `4ffd568eac2ad666a11730e6eaeb1c6b1ecc16bd`, последний release `v1.3.8` от 17 октября 2026. Это тот же коммит, который указан в аудите v0.4.1. В проекте лежит каталог Mihomo/Xray шаблонов, закреплённый на отдельной ревизии assets; локальные тесты проверяют список шаблонов по ядру и разбор JSONC. Проверка фиксирует только выбранные сценарии, не является полной сравнительной проверкой всех экранов/эндпоинтов upstream.

## Выполненные пользовательские требования

- Журнал обновляется автоматически; кнопки паузы, копирования и скачивания отсутствуют. Очистка сохраняется в браузере между перезагрузками, не удаляя системный лог-файл. Фильтр, переключение журнала и полноэкранный просмотр доступны.
- Кнопки очистки и разворота имеют одинаковую геометрию; очистка выделена; полноэкранный режим закрывается Escape. Отображение уровней и статусов запуска/остановки оформлено отдельными цветами; текст журнала стал контрастнее.
- В редакторе конфигурации шаблоны выбираются для активного ядра. Поддержанные пункты импортируются как локальный черновик; неприменимые действия проверки/форматирования/скачивания удалены из меню.
- DNS-раздел показывает статус DNS Override, DNS Mihomo, port 53 и router DNS; управление находится рядом со статусом. Имена DNS полей английские; пояснения доступны наведением и клавиатурным фокусом. Высота textareas соответствует числу значений.
- `redir-host` возвращает фактические IP адреса; `fake-ip` выдаёт клиентам виртуальные адреса и может конфликтовать с исключениями и правилами. Переключатель DNS описывает передачу IPv4; IPv6, статические DoH/DoT могут обходить настройку.

## Проверки и ограничения

- v0.4.3 commit `56c27ea`; все CI jobs прошли в run `39124537081`: frontend, backend, installer, router-aarch64.
- Локально: 216 frontend tests, typecheck, production build.
- Публичный AArch64 asset скачан заново; SHA-256 `d5096477683f8751fa3b751b1d8eb7e80b7fde97358f24870271f3c70d37a681` совпал с `SHA256SUMS`. Опубликованный release tag `v0.4.3` указывает на commit, собранный в CI.
- Отдельной серверной авторизации и пользовательских сессий нет. Same-origin проверка мутаций не защищает данные от неавторизованного клиента, если API выставлен в сеть. Использовать VPN или авторизованный reverse proxy.
- Проверки не проводились на пользовательском Keenetic. Прохождение CI не доказывает совместимость со всеми моделями, версиями KeeneticOS, конфигурациями DNS и ядрами.
- Полное восстановление DNS исходного состояния, Geo scan, полный route tester, HTTP preview подписок, multi-router/plugin config и Xray DNS остаются вне текущего релиза.
