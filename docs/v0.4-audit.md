# Аудит XKeen UI v0.4.1

Аудит выполнен 18 октября 2026 года по основной ветке проекта после PR #37 и #38. Для сравнения сценариев использован `zxc-rv/XKeen-UI` (`main` SHA `4ffd568`, release `v1.3.8`). Рассматривались возможности и пользовательские потоки; код upstream не переносился. Отдельного технического задания в рабочем каталоге нет, поэтому требования определяются сообщениями и скриншотами пользователя.

## Результаты

- Журнал обновляется автоматически, без кнопки паузы; строки событий показывают сообщение, время и уровень, а фильтр и полноэкранный просмотр остаются доступны.
- Импорт шаблонов показывает каталог для активного ядра (Mihomo или Xray) и добавляет шаблон как черновик конфигурации. Каталог шаблонов закреплён на ревизии upstream assets `8747e7b02af1631fff048bf2d832d3e5370bdb34`.
- В конфигурационном меню удалены неготовые действия ручной проверки, форматирования и скачивания черновика.
- DNS-раздел объединяет статус DNS KeeneticOS/Mihomo, диагностику и настройки Mihomo. Английские названия полей снабжены русскими подсказками по наведению и клавиатурному фокусу. Переключатель передачи DNS изменяет только IPv4 DNS роутера; статические IPv6 DNS и DoH/DoT могут обходить перенаправление.
- `redir-host` возвращает реальные адреса и обычно совместимее; `fake-ip` выдаёт виртуальные адреса и может конфликтовать с исключениями или политиками XKeen. Применение конфигурации проверяется активным Mihomo и имеет механизм отката.
- Гео-сканер, полный тест маршрутов, предпросмотр HTTP-подписок, multi-router через плагины и полноценные аккаунты/сессии не входят в релиз. DoH/DoT и фильтр контента не управляются полностью.
- Полной системы аккаунтов/сессий нет. Не публикуйте панель в открытом интернете без VPN или авторизованного шлюза.

## Проверки и ограничения

Локально пройдены 215 frontend-тестов, typecheck и production build; `git diff --check` чистый. Все четыре CI jobs прошли для release commit `253199b` (run `39121693568`); публичный AArch64 архив сверён с `SHA256SUMS`. Проверка на пользовательском роутере не выполнялась; CI не доказывает поведение всех моделей Keenetic и конфигураций DNS.
